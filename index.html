How timing works

Use the original recording rate, not the exported video's FPS. An 8× slow-motion file represents 0.125 real seconds per playback second. Automatic mode uses the declared capture rate and the playback cadence. Edited clips or variable-speed slow motion can need a manual override. The same timing must apply to all selected ranges.

A quick guide

  1. Open an original video. Both signals must be visible in the same recording.
  2. Select Reference and Output. Drag small boxes inside the changing patches, or click for a 12 × 12 pixel region.
  3. Add ranges. Select a segment with the timeline zoom handles, then choose Add range. From and To follow the selection and can also be edited. Add each usable section. Analysis uses only the added ranges; gaps are excluded.
  4. Choose recording timing. Capture FPS is detected from explicit recording metadata when available. You can override it with real-time, slow motion or capture FPS. Unknown timing gives curves without milliseconds.
  5. Explore the timeline. One fixed timeline shows the playhead and colored ranges. Drag to seek; double-click a range to zoom into it. The translucent zoom selection sits on the same track as the colored ranges. Drag its handles to resize the analysis view, or Shift+drag the track to pan. The signal analysis stays below.
  6. Set a brightness threshold. Use automatic detection per region or choose a value from 0 to 255. The threshold is applied to the region’s average brightness.
  7. Analyze and inspect. Select a result to jump to that transition. Changing settings keeps your last results visible. Select Analyze to replace them when the new analysis finishes. Export downloads the displayed results as CSV files and a report in one ZIP.

Use clear flashes at irregular intervals. Exposure, clipping, movement and rolling shutter can affect the measurement.
